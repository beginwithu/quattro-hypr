# Quattro icon font

The private-use glyphs in `quattro.ttf` are:

- `U+E900` — Quattro
- `U+E90F` — Tailscale, from <https://simpleicons.org/icons/tailscale.svg>

The marks are monochrome so the menu and bar widgets can render them using the
active theme's foreground and selection colors (`iconFont: "quattro"`,
registered via [`50-quattro.conf`](../../fontconfig/conf.avail/50-quattro.conf)).
